# Batman Return To Arkham: Arkham Asylum - MOD Latino para PS4

MOD de doblaje en español latino para Batman: Arkham Asylum (Return To Arkham) en PS4. Reemplaza todos los audios del juego en inglés por una adaptación completa al español, con voces originales de la comunidad de doblaje hispanohablante.

## Datos del juego

- **Título:** BATMAN Return To Arkham — Arkham Asylum AUDIO LATINO
- **Peso BASE:** 18GB
- **Peso UPDATE MOD:** 8,8GB
- **ID:** CUSA04607

## Características

- Doblaje completo al español latino
- Instalación por PKG: juego base + actualización 1.02 con el MOD incluido
- Se recomienda desactivar los subtítulos para una mejor experiencia

## Instalación

1. Instala el PKG del **juego base**
2. Instala el PKG de la **actualización 1.02 MOD Latino**
3. Ejecuta el juego (el MOD reemplaza esos audios por el latino)
4. Desactiva los subtítulos para una mejor experiencia
